# 《霓虹猎手》美术规范 v1（Art Bible）

> 建立日期：2026-09-14 · 状态：生效中
> 适用范围：v2.0 美术重做起，**所有**游戏素材（角色/背景/图标/UI/品牌/特效）
> 核心原则：**调色板之外不取色，网格之外不摆像素。** 一致性靠流程硬控，不靠感觉。

---

## 1. 美术方向

- **风格**：精致像素风（refined pixel art），赛博朋克夜城
- **气质**：冷峻、霓虹、底层佣兵。参考调性：Katana ZERO 的利落 + VA-11 Hall-A 的夜色
- **明确排除**：视频抽帧管线（v1.4 方案，残留/帧间漂移不可控，已废弃）；AI 直出图标（30 个图标必出 30 种风格）

## 2. 基准网格与分辨率

| 项 | 规格 |
|---|---|
| 角色单帧 | 64×64px，人物主体占高约 48~56px |
| 对齐网格 | 8px |
| 游戏内显示 | 2× 整数倍放大 + `image-rendering: pixelated` |
| 基线 | 角色脚底统一对齐帧内 y=60（64 格内） |
| 背景 | 960×540 基准，视差层分离导出 |
| 图标 | 32×32px（游戏内 2× 显示），8px 网格 |
| sprite sheet | 横排、格宽 64、无间距、无 padding |

## 3. 固定调色板（14 色，唯一取色来源）

| 分组 | 色值 | 用途 |
|---|---|---|
| 夜色底 1 | `#0A0D18` | 最深阴影 / 1px 外描边 |
| 夜色底 2 | `#131829` | 阴影层 |
| 夜色底 3 | `#1E2540` | 背景中景 |
| 夜色底 4 | `#2C3554` | 背景远景 / 暗部过渡 |
| 灰阶 1 | `#46506B` | 服装/装甲暗部 |
| 灰阶 2 | `#5F6B87` | 服装/装甲中间调 |
| 灰阶 3 | `#8B96B3` | 服装/装甲亮部 |
| 灰阶 4 | `#C7CEE0` | 高光面 |
| 霓虹青 | `#00E5CC` | 主霓虹（能量/刀刃/义体光） |
| 霓虹青亮 | `#66FFF0` | 霓虹高光（少量点缀） |
| 品红 | `#FF2E88` | 副霓虹（Boss/危险/暴击） |
| 品红亮 | `#FF7AB8` | 品红高光（少量点缀） |
| 电光橙 | `#FF9F1C` | 金币/奖励/补给箱提示 |
| 高亮白 | `#F2F5FF` | 最强高光（单帧不超过数像素） |

规则：
- 任何素材**只允许**使用以上 14 色（抗锯齿过渡色由量化脚本归并到最近色）
- 霓虹青亮 / 品红亮 / 高亮白为点缀色，单帧合计不超过画面 5%
- 换色变体只换灰阶组+一个霓虹色，夜色底组不动

## 4. 光影规范

- 主光源：左上 45°（夜城冷光）
- 轮廓光：右下霓虹反光（rim light，1~2px，角色用霓虹青、Boss 用品红）
- 外描边：1px `#0A0D18`，所有角色/图标强制
- 禁止：每个素材自定义光向、全局光照、柔边渐变

## 5. 动画帧规范

| 动画 | 帧数 | 说明 |
|---|---|---|
| idle | 4 帧 | 呼吸浮动 ±1px，循环 |
| attack | 8 帧 | 起手 2 / 挥砍 3 / 收势 3，第 4~5 帧为命中帧 |
| hit（受击） | 2 帧 | 白闪 + 后仰，可选 |
| death | 4 帧 | 倒地/消散，Boss 必备 |

- 命中帧刀光允许短暂超出身体轮廓，但不得超出 64 格
- 帧间位移不得超过 4px（防抖动），逐帧过质量门

## 6. 生产管线

### 角色（AI 逐帧精做）
1. 概念定稿：AI 立绘 → 人工确认造型（返工只在这步返）
2. 锚帧：概念稿像素化为第 1 帧，量化进调色板，作为全部帧的参考图
3. 逐帧生成：以锚帧为参考逐帧生成（或整帧条 4 帧/条，一致性更好）
4. 后处理（Python 脚本批量）：调色板量化 → 边缘清噪 → 基线对齐 → 拼 sheet
5. 质量门：连续播放查抖动，单帧不达标单独重做该帧

**生产硬规则（v1.5 实战教训）**：
- **帧条必须用品红键控底 `#FF00FF`**——深色角色配深色底无法抠图（暗部与背景同色无封闭轮廓，任何颜色键控都会镂空）。概念稿可以用氛围底，生产帧条一律键控底
- **姿态幅度收敛**：身体保持直立紧凑、双脚不离地、不过度拧转——大动作在 64×64 下会散架。攻击动感靠刀刃弧线表达，不靠身体
- 刀刃等细长件在提示词中要求"连续不断开"，否则微粒清理会把断截当噪点清掉

### 图标 / UI（矢量自制）
- 先在 8px 网格上出矢量稿，再导出 32×32 像素化，同一套设计语言（圆角 2px、描边 1px、霓虹单点缀）

### 背景（AI 大图 + 人工修整）
- AI 生成 1920×1080 → 裁 960×540 → 调色板量化 → 视差层手工分离

## 7. 文件与命名

```
game/assets/
  player_idle_sheet.png / player_attack_sheet.png
  enemy1_idle_sheet.png …（enemy1~4 为换色变体）
  boss_idle_sheet.png / boss_attack_sheet.png / boss_death_sheet.png
  bg_layer1_far.png / bg_layer1_near.png …（layer1~3 = 街区/企业区/云顶）
  icons/（装备、技能、货币，32×32 单图）
  fx_slash.png / fx_hit.png / fx_levelup.png
asset-src/
  concept/（概念稿，不进部署包）
design/tools/（后处理脚本，后续建）
```

- 包体预算：素材总量 **< 2MB**（像素风压缩后预估 600KB~1MB）
- 所有进包 PNG 必须过 pngquant/oxipng 压缩
