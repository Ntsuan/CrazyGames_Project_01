# v2.76 背景音乐响度调整

2026-09-28 · 本次修改由 **Codex** 完成。用户反馈“背景音乐太轻，几乎听不见，尤其封面的BGM”。以最新v2.75为基线，保留封面仅显示版本号等其他改动；仅更新WorkBuddy实际工程，未同步Git或发布。

## 原因与改动

v2.74接入时对母版施加-8dB基础增益，又乘默认60%音量（约-4.44dB）。M03母版比战斗曲低约3 LU，导致封面尤其轻。之前按母版估算默认约-35.4 LUFS；本轮对实际MP3解码实测后，默认60%约为-35.70 LUFS。

| 参数 | v2.75 | v2.76 |
|---|---|---|
| Music基础增益 | -8dB | 0dB |
| M03独立补偿 | 0dB | +6dB |
| M01／M02／M04独立补偿 | 0dB | 0dB |
| 默认滑块／已有用户设置 | 默认60%、保留已有值 | 不变 |
| 主炮预警／短面板压低 | 额外-6dB | 不变 |
| 封面／重塑M03同滑块实际增幅 | — | +14dB |
| 战斗M01／M02／M04同滑块实际增幅 | — | +8dB |

新默认60%下，M03约-21.70 LUFS，三首战斗曲约-24.71 LUFS；目标是封面明确可听、战斗仍给音效留空间。这里是信号测量／计算，不把它写成用户听感已经通过。

`game/index.html`新增`MUSIC_GAIN_DB`，每个音乐声源保存自己的`level`，进入、退出及取消交叉淡化均使用对应增益，避免目标曲M03的+6dB在总线上误放大源曲。Music总线仅处理用户滑块及压低。不修改音频文件、音高、循环长度、速度、战斗经济、存档成长或v2.75封面显示；音乐关闭和音量0继续保持静音。

文件：`game/index.html`、`game/CHANGELOG.md`、`game/versions/index_v2.76.html`及本轮交接文档。快照与主HTML逐字节相同。4首MP3及65个原音效共69文件哈希与[基线](audio-baseline.json)全部一致。
