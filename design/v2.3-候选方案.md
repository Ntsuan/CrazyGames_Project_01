# v2.3 候选方案（✅ 已全部实施于 v2.3）

> 2026-09-16 · 状态：**已全部落地**

## 0. 全自动装备（2026-09-16 用户需求）

- **取消手动装备**：获得/合成装备时，品质高于当前已装备 → 自动换上（换下件回背包作合成材料）
- 固定词条下同部位同品质完全同构，"最高品质"即唯一比较键，无并列歧义
- 移除：背包图标点击装备、btnAuto「穿上更强义体」按钮、"点击装备"提示
- 背包定位随之变化：纯材料池（合成/拆解用），装备栏全自动
- 日志：equip 事件统一由自动逻辑产生（保留 autoequip 事件名）
- UI 简化：背包图标不再可点，仅悬停显示描述；合成/拆解按钮保留

## 0.1 词条改为固定（2026-09-16 用户决策）

- **取消随机词条，改为固定词条**——连带解决堆叠口径问题：同部位同品质装备完全同构，天然严格堆叠，无需二选一
- 建议的固定词条表（橙装起生效，沿用现有数值池）：

| 部位 | 固定词条（q≥4） | 理由 |
|---|---|---|
| 义体武器 | 暴击率 +5% | 攻击位给暴击，Build 核心 |
| 神经插件 | 攻速 +10% | 攻速位强化本职 |
| 皮下装甲 | 吸血 +3% | 生存位给续航 |
| 芯片 | 无词条（或 信用点额外 +10%，待定） | 芯片主属性已是经济向 |

- 合成品 q≥4 不再重 roll 词条，直接继承部位固定词条
- 旧存档兼容：load 时把已有随机词条装备归一为部位固定词条（或保留旧词条视为合法，新装备用固定——建议前者，统一干净）

## 1. 同部位同品质装备堆叠

- 背包内相同（部位+品质）的装备合并为一格，**图标方框右下角显示数量角标**（如 ×3）
- 堆叠格视觉即"可合成进度"：数量 ≥3 时角标高亮，配合合成按钮
- ~~待决点：词条堆叠口径~~ → 已由"固定词条"决策消除：同部位同品质完全同构，严格堆叠

## 2. 背包排序：品质高在左

- 每部位栏内按品质降序排列（高→低从左到右）
- 同品质按获得时间（先获得在前）
- 配合堆叠后，栏内视觉 = "神话×2 传说×1 蓝×5 …"一眼读出资产结构

## 连带影响

- `equip(i)` 按索引装备的逻辑要改为按（部位+品质+组内序号）定位
- fuseInfo/fuseSlot/salvage 的遍历不受影响（按品质组操作，天然兼容堆叠）
- 掉落 toast 不变；日志 drop 事件不变
