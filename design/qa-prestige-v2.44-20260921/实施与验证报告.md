# 每 10 层可选重塑：实施与验证报告

日期：2026-09-21。修改者：**Codex**。基线 v2.43 → **v2.44**。

用户已通过交互方案及 UI 参考并要求执行。功能已在本地实现，未部署；广告仍为明确标识的测试模拟，未接入真实广告 SDK。

## 玩家可见变化

- 第 10、20、30……层 Boss 掉落结算、完整退场后，暂停并提示“继续挑战，还是重塑变强？”。包括第 100 层。
- 继续挑战：进入原有技能三选一，之后前往下一层；同一轮同一里程碑处理一次。
- 前往重塑：先预览本轮碎片和装备回收信用点；可返回选择。普通重塑结算 N 碎片；广告模拟完整观看后结算 2N。
- 翻倍仅作用于本轮未结算碎片，不翻倍账户已有碎片或装备回收信用点。
- 显示重置与保留规则，普通与广告按钮同尺寸；小屏和横屏可在弹窗内滚动。键盘焦点限制在重塑弹窗内。
- 取消或广告失败返回预览，保留本轮。死亡／受阻仍必须重塑，没有返回活着继续挑战的入口。

## 实现与数值边界

主要修改位于 game/index.html：

| 位置 | 变化 |
| --- | --- |
| onKill | Boss 奖励后创建并保存里程碑意图，退场后先显示重塑选择，再分支到技能 |
| freshState / openingRunIn | 增加并恢复 prestigeOffer、lastPrestigeMilestone、lastPrestigeId；待处理选择优先于新层开战 |
| showPrestigeOffer / continueMilestone / backToMilestone | 通关提醒、预览、返回、继续流程 |
| doPrestige / applyPrestige | 结算前预览；同一存档项一次性提交奖励与已消费意图，写失败不结束本轮 |
| requestPrestigeAd / finishPrestigeAd | 显式测试模拟；请求与完成分离，按请求序号、流程代次与结算 ID 拦截旧回调 |
| checkWall / showWallModal | 受阻及预览可持久恢复；刷新不得绕过当前受阻重塑 |
| showModal / cancelReset / doReset | 焦点、滚动和复位取消恢复；重塑/复位清理旧技能、转场与广告请求 |
| renderPanels / VERSION | 更新重塑说明，版本 v2.44 |

重塑触发从“仅受阻”扩展为“每通关 10 层可选，受阻保留原出口”。奖励倍数 1/2、回收率 15%、战斗成长、装备掉落及加成树参数均未修改。里程碑回收沿用原计算公式，但明确用**刚通关层**估值；不使用内部已递增至下一层的 floor，多算 15% 的楼层系数。死亡回收仍按受阻层。

收益在创建提示时冻结，包含刚击败 Boss 的掉落。确认前不重置资源。写入成功后作废旧技能候选与转场；广告完成但写失败时保留成功资格，允许直接重试翻倍结算，不重复要求观看。

## 主动重塑节奏观察

5 个随机种子 × 3 种策略 × 每种 3 轮，30 FPS 虚拟时钟，使用真实游戏函数；固定升级倾向、自动合成、选首个技能、重塑后投伤害树、已通关层 2×。不领补给、不计广告奖励和广告耗时，也不计真人操作延迟。

| 策略 | 15 轮累计碎片 | 总秒数 | 碎片/分钟 |
| --- | ---: | ---: | ---: |
| 通关 10 层即重塑 | 171 | 3508.6 | 2.924 |
| 尽量通关 20 层重塑，提前受阻则结算 | 337 | 7103.1 | 2.847 |
| 持续挑战到受阻 | 407 | 8672.6 | 2.816 |

这组样本中 10 层策略略高，不能据此断言长线或真人体验已平衡。提前重塑会改变首次永久成长时机；本次按已通过需求保留奖励，不额外加冷却或压低碎片。建议真人比较首次成长速度、提醒打断感及反复打低层的倾向。
