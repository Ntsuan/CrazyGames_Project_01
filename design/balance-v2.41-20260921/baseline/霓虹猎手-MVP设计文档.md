# 《霓虹猎手》（Neon Hunter）— MVP 设计文档

> 版本：v1.1（2026-09-11，v0.4 实测调参后同步） · 平台：CrazyGames（HTML5） · 品类：放置战斗 / 爬塔
> 状态：数值模型经"仿真 + 实测数据"双重校验，可直接照此开发

---

## 1. 一句话概念

**你是一名夜城底层佣兵，从街头一路杀上企业巨塔顶层——自动战斗、爆出义体、卡关就"重塑"重来，每一世都比上一世更强。**

### 题材包装（赛博朋克）

| 系统 | 世界观叫法 |
|---|---|
| 楼层 | 企业塔层（1层=街头，100层=企业顶层） |
| 装备四部位 | 义体武器（螳螂刀）/ 神经插件 / 皮下装甲 / 芯片 |
| 转生 | 「重塑」——备份人格，换一具更强的克隆体 |
| 转生货币 | 记忆碎片 |
| 金币 | 信用点 |

备选名：《夜城猎手》《塑命佣兵》。先不定死，美术阶段再定。

---

## 2. 核心体验承诺

> **看着角色自动变强，每隔几分钟做一次真正重要的决策。**

- 玩家 80% 时间享受被动爽感（数字暴涨、爆装、推层），20% 时间在机遇时刻决策（换装、技能三选一、重塑时机）
- 绝不用弹窗频繁打断玩家；决策只出现在关键节点

## 3. 核心循环

```
自动战斗 → 掉信用点/义体 → 强化 → 推层
   ↑                                ↓
离线收益 ← 「重塑」(永久加成) ← 卡关(Boss打不过)
```

单会话节奏：上线收离线收益 → 推几层 → 卡关 → 看广告翻倍/开宝箱 → 重塑或下线。

## 4. 数值模型（已锁定，仿真验证通过 ✅）

### 4.1 玩家成长

| 项 | 公式 | 说明 |
|---|---|---|
| 攻击力 | `ATK = 8 × 1.10^a` | a = 攻击等级（v0.11 基数 6→8，开局提速） |
| 生命值 | `HP = 100 × 1.10^h` | h = 生命等级 |
| 攻速 | 固定 1.3 次/秒（v0.11 由 1.0 上调） | 由技能/词条提供乘区 |
| 升级成本 | `cost = 6 × 1.22^n` | 攻/血共用一条成本曲线（v2.13 由 1.18 上调：首卡提前，S24 真人 f65/40min 太晚） |

### 4.2 怪物难度（f = 层数）

| 项 | 公式 |
|---|---|
| 小怪血量 | `20 × 1.15^f` |
| 小怪攻击 | `1.5 × 1.14^f` | v2.13 由 1.13 上调（生存压力是首卡主驱动） |
| 小怪金币 | `0.10 × 小怪血量`（v0.4 由 0.12 下调） |
| Boss（每层第 6 只） | 血 ×6 / 攻 ×1.8 / 金币 ×5 |

**核心设计：难度增长率 1.15 > 成长率 1.10**，差距制造自然卡关点——这是重塑的触发器，必须存在，不能让玩家无脑平推。

### 4.3 卡关判定

- 击杀单只怪耗时 > 90 秒，或站不住（承受伤害 > 生命上限）→ 判定卡关
- 卡关时弹出「重塑」引导（不强制，可继续磨）

### 4.4 仿真与实测校验

**第一轮（v1.0 纯基础模型）**：首卡 36 层 / 27.2 分钟。
**实测修正（v0.4）**：测试段 S02 实测 51 层未卡关——玩家真实战力 ≈ 基础值 ×3（装备+技能），模型漏算导致过易。
修正后模型加入装备/技能等效倍率（攻 `min(3.0, 1+0.08f)`、血 `min(1.7, 1+0.03f)`、攻速 `min(1.66, 1+0.02f)`），
并将成本上调至 1.16、金币下调至 0.10，卡死"收入∝战力"的追赶回路：

> **v0.4 预期：首卡 43 层 / 19.3 分钟** ✅（仿真脚本 `design/sim.py`，已含装备修正）

**S05 实测修正（v0.9，不改数值只加信息）**：真实玩家偏科堆攻击（有效生存 = 生命×DPS，攻击隐性附带收入优势，
理性策略非错觉），首卡提前至 26 层 / 9.2 分钟（hp_zero）。10 分钟完整循环贴合 CrazyGames 短会话特性，
**难度冻结**。HP 成长 1.12 补偿方案经仿真否决（首卡推至 56 层/32min，破坏节奏）。
v0.9 改为提供 Boss 生存预估（预估承伤 vs 生命），把攻血取舍变成知情博弈。

### 4.5 重塑（Prestige）

| 项 | 公式 / 规则 |
|---|---|
| 记忆碎片 | `souls = (f / 10)^1.5 × (1 + 0.1×灵魂共鸣Lv)`（f = 历史最高层；v2.0 起含树加成） |
| 首次重塑（36层） | ≈ 6 碎片 |
| 碎片加成树 | 伤害 +5%/级、信用点 +10%/级、离线收益 +10%/级、灵魂共鸣（碎片获得）+10%/级——**均无上限**（v2.0 起） |
| 树成本 | **当前等级+1 碎片/级**（v0.10 修正：固定 1 碎片/级会被一次长会话点穿，S09 实测） |

### 4.6 离线收益

- 按历史最高层推进效率的 **60%** 结算
- **上限 8 小时**（制造"该上线了"的召回点）
- 回归弹窗：「你离线期间，猎手替你战斗到了第 X 层」+ 看广告 ×2

## 6. 装备系统（义体）

- **4 部位** × **品质无上限**（v1.7）：民用(白) / 改装(绿) / 军用(蓝) / 原型(紫) / 传说(橙) / 神话 / 永恒 / 不朽 / 不朽+n
- 主属性为**百分比加成**（随成长自然缩放，不用做数值表）：

| 部位 | 主属性 | 白 | 绿 | 蓝 | 紫 | 橙 |
|---|---|---|---|---|---|---|
| 义体武器 | 攻击 +% | 10 | 25 | 45 | 70 | 100 |
| 神经插件 | 攻速 +% | 5 | 10 | 18 | 28 | 40 |
| 皮下装甲 | 生命 +% | 10 | 25 | 45 | 70 | 100 |
| 芯片 | 信用点 +% | 10 | 20 | 35 | 55 | 80 |

- **橙以上扩展**：`mult(q) = mult(橙) × 1.35^(q-4)`（v2.0 由 1.45 回调：神话 135% → 永恒 182% → 不朽 246%…）
- **合成（v1.7）**：背包同部位同品质 3 件 → 1 件高 1 阶，无上限；q≥4 的合成品必带词条；材料需求 3^n 指数增长 = 天然软上限
- 传说(橙)及以上额外带 1 条随机词条：暴击率 +5% / 攻速 +10% / 吸血 +3%
- **掉率（v1.8：掉落区间随楼层上移，高层不掉无效低品质）**：

| 楼层 | 区间 | 概率 | 合成链目标 |
|---|---|---|---|
| 1–24 | 白 ~ 蓝 | 60/30/10 | 上蓝 |
| 25–49 | 绿 ~ 紫 | 60/32/8（v2.0 回调：紫 13→8） | 上紫 |
| 50–74 | 蓝 ~ 橙 | 60/34/6（v2.0 回调：橙 13→6） | 上橙 |
| 75+ | 紫 ~ 橙 | 80/20（v2.0 回调：橙 35→20） | 橙进合成冲神话 |

- **橙以上合成倍率回调（v2.0）**：`mult(橙) × 1.35^(q-4)`（原 1.45，S16 实测装备乘区过陡）

- 小怪掉率 25%，Boss 必掉；**保底：连续 10 次未出区间最高档，下次必出**
- **背包（v1.8）**：无上限，按部位四分栏展示；已装备参与合成、产物直接装备；
  可拆解比已装备低 2 档及以上的白~紫件换金币（橙+不拆）
- 新装备自动对比，一键换装（不让玩家做算数题）

## 7. 技能池（每 10 层一次三选一，**无上限，同名叠加升级**——v1.7 起）

| 流派 | 技能 | 效果 |
|---|---|---|
| 暴击流 | 战斗超频 | 暴击率 +10%（可叠加） |
| | 致命固件 | 暴击伤害 +50% |
| | 杀戮循环 | 暴击后攻速 +20%，持续 3 秒 |
| 普攻流 | 神经加速 | 攻速 +15% |
| | 火力协议 | 攻击 +25% |
| | 电弧溅射 | 攻击附带 20% 溅射伤害 |
| 生存流 | 皮下加固 | 生命 +30% |
| | 纳米修复 | 吸血 +5% |
| | 应急护盾 | 每场战斗开始时获得 10% 最大生命的护盾 |
| 通用 | 黑市渠道 | 信用点 +30% |
| | 碎片共鸣 | 本次重塑碎片 +20% |
| | 肾上腺素 | 击杀后 2 秒内攻速 +30% |

设计要点：三选一制造局内 Build 感。v1.7 起取消 5 次上限、同名叠加升级——深局成长有持续惊喜；
仿真验证其成长速率（≈+1.4%/层）远小于怪血增速（15%/层），不会破坏卡关节奏。

## 9. 美术与技术方向

- **表现**：横屏 2D 小人对砍（左侧玩家 vs 右侧敌人），2~3 帧攻击动画 + 伤害飘字 + 屏幕震动
- **色调**：深底 + 霓虹青 `#00F0FF` × 品红 `#FF2A6D`，故障(glitch)转场
- **素材**：AI 生成 sprite + 免费素材，风格统一优先于精度
- **技术**：纯 HTML + JS（Canvas），包体目标 < 5MB；CrazyGames SDK v3（广告、云存档、埋点）

## 10. MVP 开发路线

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| 1. 数值原型 | 纯文字/色块实现核心循环 | 挂着玩 30 分钟不腻，首卡点 25~40 层 |
| 2. 调数值 | 自己玩 + 3 个朋友玩 | 想"再推一层"，无"不知道干嘛"时刻 |
| 3. 套美术 | AI 生成 sprite、霓虹 UI | 截图放 CrazyGames 首页不违和 |
| 4. 接 SDK | 广告 ×3 点位、云存档、埋点 | 广告点位全触发，存档跨设备 |
| 5. 提交审核 | 预留 1~2 周 | 过审上线 |

**MVP 不做**：多货币、公会、PvP、剧情、成就系统。一律等上线数据说话。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 后期数值膨胀失控 | 数字用缩写显示（K/M/B/T），公式本身已自洽 |
| 放置类在 CrazyGames 同质化 | 靠赛博朋克美术记忆点 + 爬塔题材差异化 |
| 首卡时机实测偏离仿真 | sim.py 已参数化，改数字重跑即可，10 分钟一轮 |
| 新手前 3 分钟流失 | 1 层即给首次升级、3 层首件绿装、5 层首只 Boss——爽点前置 |
