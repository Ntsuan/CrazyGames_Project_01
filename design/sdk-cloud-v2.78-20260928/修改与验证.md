## 实现

- `game/assets/platform.js` 在 CrazyGames 域名和本地 SDK 预览加载官方 SDK v3。先 `init()` 再开放游戏存档；平台 Data 不可用时停在封面，支持重试和原始备份导出。普通非平台部署继续使用本地存档。
- Data 使用单一 `neonHunter.progress.v1` 项，版本化封装无尽、构筑和模式配置三个槽位。首次接入时验证并迁移旧 localStorage 项，保留原项作备份；云端已有数据时直接使用云端，不合并资源或重复导入。写入时检查版本冲突和900KB上限，SDK写失败不提交内存版本。
- 游戏读取、自动保存、阶段改装、重塑、补给、模式切换及复位统一使用进度存储入口。封面在存档初始化前禁用开始和模式按钮；实战可玩状态切换时调用 Game `gameplayStart/Stop`。登录由 SDK 自动重载；监听登录后禁止旧局继续写入，云档模式卸载时不再写旧局快照。
- 新增连接状态、失败、备份提示的英文词条。Basic不请求广告；开发版原有模拟广告不变。Full继续禁止出包，等待广告接入与平台验收。
