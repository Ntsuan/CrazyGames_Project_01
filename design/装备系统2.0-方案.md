# 装备系统 2.0 方案（v1.8 候选，待确认）

> 2026-09-15 · 基于用户 4 条调整需求整理 · 未动代码

## 需求 → 规则映射

| # | 需求 | 方案 |
|---|---|---|
| 1 | 背包没有上限 | 移除 12 件上限与丢弃逻辑，容量无限（合成是天然回收口） |
| 2 | 四装备分四类 | 装备面板改为**四分栏**：每部位一栏（已装备在顶、背包件在下），互不混排 |
| 3 | 已装备参与合成，合成后直接装备 | 合成计数 = 该部位背包同品质数 **+ 已装备（若同质）**；产物**总是直接装备**，被换下的旧件回背包 |
| 4 | 掉落品质与楼层的关系 | **保底品质随楼层抬升**（见下），保证高层掉落永远能进合成链 |

## 第 4 点的分析（用户问"是否考虑过"）

**旧设计的问题**：掉落封顶橙 7%（51+ 层），白/绿仍占 45%。有了合成后，高层掉白绿约等于废物——白→橙要 81 件白，高层玩家根本不会去凑。

**方案：掉落区间随楼层上移**

| 楼层 | 掉落区间 | 概率分配（区间内） | 效果 |
|---|---|---|---|
| 1–24 | 白 ~ 蓝 | 60/30/10 | 开局靠合成上蓝 |
| 25–49 | 绿 ~ 紫 | 55/32/13 | 合成链目标：紫 |
| 50–74 | 蓝 ~ 橙 | 55/32/13 | 合成链目标：橙 |
| 75+ | 紫 ~ 橙 | 65/35 | 橙进合成链冲神话 |

- 保底机制保留并改为"区间内最高档"：连续 10 次未出最高档 → 必出
- 数值影响：高层装备乘区提速，但仍在 3^n 合成成本的软上限内（仿真已验证此类增速 << 怪血 15%/层）
- 附带好处：**出售和合成永远有意义**，背包不再堆积"看着烦的垃圾"

## 合成规则定稿

- 每栏独立显示该部位各品质的"件数/3"进度；凑满（含已装备）栏内出现合成按钮
- 一键合成只处理该栏（不再全局一键，避免误合）——点击后循环升阶直到 <3
- 产物必装备（旧装备回背包）；q≥4 产物必带词条（沿用 v1.7）
- 出售按钮保留在每件上（高层垃圾换金币的退路仍在）

## UI 方案（见上方 mockup）

- 四栏等宽，栏头 = 部位名；已装备卡 = 品质色描边 + 倍率
- 背包件 = 品质色小方块（chips），数量直观，不再滚动列表
- 可合成状态：实色按钮（含已装备凑满时用虚线提示"紫×2+已装备=3"）
- 移动端：四栏 2×2 折行（现有 flex-wrap 机制兼容）
