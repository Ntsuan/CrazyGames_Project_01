## 3. 实现与时序变化

实际修改入口为 `game/index.html`：

- `afterPresentation / syncPresentationSpeed`：每个演出任务记录剩余的 1× 毫秒数，切速先扣除已经消耗的进度，再按新速率排定余下回调。计时使用 performance.now，演出在战斗暂停的跑入/转场阶段仍继续。
- 精灵 CSS 保留 1× 基础 duration，使用 Animation.playbackRate 调整速度。切速不重设已播进度；新增动作也立即同步当前倍率。
- `presentationTween`：玩家、敌人位移、淡出、背景滑动使用可调播放速率的动画；取消旧动画时清理其结束任务。
- `beginPresentationRun`：复位、重塑和开始新转场时更新代次，清掉旧演出任务、位移动画、背景层与死亡监听。
- `checkWall`：死亡前清理实际攻击态 `atk`；真实 gunnerDeath 结束负责弹窗，1200ms 演出时间兜底随倍速变化；首次完成即撤销另一条路径。受阻后购买生命升级不会意外取消受阻弹窗。
- `enemyRunIn` 默认绑定当前代次，并清除上一敌人的攻击/蓄力等状态；玩家射击清理也纳入演出时钟。

| 时序项 | v2.39.2 | v2.40 |
|---|---|---|
| 角色精灵 | duration 随倍速改写 | 基础 duration 不变，播放速率为 1 或 2 |
| 跑入/清理回调 | 创建时折算一次 | 记录剩余进度，途中切速重排 |
| 玩家射击态清理 | 固定真实 330ms | 330ms 演出时间（固定 2× 时 165ms） |
| 背景滑动/结束 | 固定真实 450/480ms | 450/480ms 演出时间（固定 2× 时 225/240ms） |
| 跑出开始淡出 | 在 1150ms 切换 transition，截断 1200ms 位移 | 完成 1200ms 位移后淡出 200ms；场景阶段仍在 1400ms 开始 |
| 跑入后缓冲 | 固定真实 +50ms | 演出时间 +50ms（2× 为 25ms） |
| 死亡兜底 | 1200÷开始时倍率，之后不变 | 1200ms 演出时间，可重排/取消；正常由 900ms 动画结束事件触发 |

移动端跑入基础 360ms、稳定等待 650ms，桌面敌人 900ms、玩家 1400ms、稳定等待 1000ms 保持原值。战斗 dt 倍速、临时 buff 的实时时钟、UI 刷新、提示、广告锁和触摸抑制计时沿用原设计。无动画 API 的降级环境仅保证回调推进；本轮画面验证针对支持 Web Animations API 的内置 Chromium。
