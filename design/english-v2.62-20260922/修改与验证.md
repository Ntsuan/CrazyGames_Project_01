# v2.62 英文化与验证（Codex）

日期：2026-09-22。基线 v2.61 → v2.62。本次修改由 **Codex** 完成。用户选择：默认英文，并保留中文切换。

## 已完成

- 首次进入默认为 English；封面右上角 Settings → Language 可切换 English／中文，重载后生效。切换只在封面开放；战斗中可先点 Home 返回封面。
- 语言偏好独立保存在 `neonHunter.language`；有效 `?lang=en`／`?lang=zh` 参数优先于本地偏好。没有有效设置时回退英文，不依赖浏览器语言；存储被禁用时仍可通过 URL 切换。
- 372 条英文词条覆盖封面、加载、双模式、战斗 HUD、升级、装备/品质、14 项技能、重塑/补给/模拟广告、5 个阶段及 4 段改装动画提示、确认框与测试日志界面。
- 英文标题使用 Neon Hunter；桌面/手机封面、长按钮、阶段说明作英文专用排版适配。320px 阶段导航采用两列以保留完整单词。
- 游戏数值、技能内部 ID、存档键、两模式进度规则均保持。历史日志已有的自由文本保留生成时的语言。

## 文件与维护

- `game/index.html`：VERSION、脚本与 CSS 引用、显示文本 `L()` / 模板标签、封面语言选择器及启动静态翻译。
- `game/assets/i18n/en.json`：可维护词典；`en.js`：浏览器运行词典。修改 JSON 后必须同步生成 JS（使用 JSON.stringify 输出 `window.NeonEnglish = ...;`），同时更新对应缓存版本。
- `game/assets/i18n/runtime.js`：语言选择、模板占位符、静态 DOM 翻译、缺失词条警告；`layout.css`：排版。
- `game/assets/upgrades/1-2.js`、`2-3.js`、`3-4.js`、`4-5.js`：动画提示经相同翻译入口。
- `game/versions/index_v2.62.html`：与主 HTML 一致的历史快照；运行仍依赖 game/assets，快照不是独立发布包。
- 本目录 `baseline/game/` 保存原 v2.61 HTML、CHANGELOG、四段动画；`release/game/` 保存本次改动的完整 v2.62 文件集合。
- `extract.cjs`、`migrate.cjs` 是一次性迁移记录，**不可作为日常构建执行**（会从原基线重写文件）；日后修改显示文本时应手动更新 L 包装与词典。
