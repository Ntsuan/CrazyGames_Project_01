# v2.43 裂爪巡猎蛛接入与验证

- 日期：2026-09-21；修改者：**Codex**。
- 基线：v2.42.1；交付：v2.43；**本地工程完成，未发布线上**。
- 用户要求：读取实际工程和交接，将已通过的四足蜘蛛动画作为第三种普通敌人，与安保兵、机械犬随机出现。

## 实现

1. `game/index.html` 新增 `NORMAL_MOB_KINDS`、`pickNormalMobKind()`。每次 `enemyRunIn` 为普通怪独立抽取一次，三者各 1/3。就位的 `spawnMob` 沿用入场选择，避免入场与站立换肤。
2. `spawnMob` / `enemyRunIn` 同步设置和清除 `.spider`，Boss 排除普通池；典狱长、棱镜、天枢保留各自外观与规则。
3. `game/assets/riftclaw/` 新增 4 张透明无损 WebP 横向帧条及来源清单，来自本次已通过的素材包 mobile 版。单帧 256×192，显示 128×96，适合约 2× 像素密度；四张合计 510,860 字节（约 499 KiB）。不导入原始生成图和预览文件。
4. CSS 接入待机 4 帧 / 1040 ms、行走 8 帧 / 880 ms、射击 6 帧 / 660 ms、死亡 8 帧 / 1410 ms。射击、死亡按原素材各帧不等时长切片，死亡保持有效末帧，避免落到空白切片。
5. 蜘蛛没有受击动画：`enemyAnim` 忽略其 hurt；正在射击时忽略重复 shoot，保留蓄能到回位的完整动作。死亡立即取消射击清理回调并切换死亡态。
6. 蜘蛛击杀后 1410 ms 开始 300 ms 淡出，1760 ms 开始下一只入场；安保兵/犬沿用 1300/1650 ms。全部沿用现有演出时钟，途中切换 1×/2×保留进度，复位取消旧代次回调。
7. 预加载四张 WebP，首次出现前加载资源。页面无需导入素材包的独立播放器。

## 数值与行为边界

| 项目 | 旧值 | 新值 |
| --- | --- | --- |
| 普通敌人类型概率 | 安保兵 50%、犬 50% | 安保兵、犬、蜘蛛各 1/3 |
| 蜘蛛死亡等待/下一怪入场 | 无 | 1410 / 1760 ms |
| 原普通敌人死亡等待/下一怪入场 | 1300 / 1650 ms | 原值保持 |
| 普通敌人血量、攻击、金币、装备掉率 | 按楼层统一 | 三种使用同一规则 |
| Boss 排列与参数 | 每层第 6 只，按层级选 Boss | 保持 |

当前游戏敌人使用持续伤害。蜘蛛射击只负责演出，不接入素材包 `fire` 事件作为额外伤害；否则会重复结算。攻击动画触发频率沿用原逻辑。类型不写入长期存档，遵循既有“刷新回本层起点，再随机入场”规则。

每只蜘蛛死亡流程比原普通怪长 110 ms 演出时间；以每层 5 只小怪、1/3 蜘蛛估计，平均每层增加约 183 ms（2×约 92 ms），不改变战斗或掉落参数。楼层数值表无需重算。
