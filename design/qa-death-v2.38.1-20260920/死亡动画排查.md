# 阶段 1 玩家死亡动画排查

检查版本：v2.38.1。日期：2026-09-20。只做定位及隔离页面验证，未修改游戏源码。

## 主因：素材引用名称错误

`game/index.html:63` 引用 `assets/stage01_death.png`，但实际文件为 `game/assets/stage01-death.png`。前者是下划线，后者是连字符。

浏览器验证：下划线路径加载失败，连字符路径成功加载，尺寸为 1024×128，即 8 个 128×128 帧。

死亡触发本身正常：player.hp=0 后实际 checkWall() 设置 wall/paused，添加 death class，计算样式为 gunnerDeath、0.9s，并在结束等待后显示“行动受阻”。因此本次没有播放的直接原因是素材加载失败。

## 第二处问题：结束位置越过最后一帧

素材被缩放为 880×110，单帧 110px。8 帧的合法起始位置为 0、-110、-220、-330、-440、-550、-660、-770px。

当前 keyframes 结束在 -880px，并使用 steps(8) forwards、no-repeat。实测结束位置确为 -880px，显示窗口越过整张图，最后变成空白，而非保持倒地末帧。

## 建议修改

```css
#player .psprite.death {
  background-image: url('assets/stage01-death.png');
  background-size: 880px 110px;
  background-position: 0 0;
  animation: gunnerDeath calc(var(--spd, 1) * .9s) steps(7) forwards;
}
@keyframes gunnerDeath {
  from { background-position-x: 0; }
  to   { background-position-x: -770px; }
}
```

8 个帧位置之间有 7 次跳变，上述写法遍历 8 帧并停在第 8 帧。建议将死亡素材加入启动预加载，避免首次死亡临时加载产生空白。
