## 4. 核心设计决策（已定，勿轻易推翻）

| 决策 | 内容 | 理由 |
|---|---|---|
| 品类 | 放置战斗 / 爬塔 | 图形要求低，适合新手首作；难度在数值而非编程 |
| 体验承诺 | 80% 被动爽感 + 20% 关键决策 | 放置品类的乐趣本质 |
| 难度增长 > 成长增长 | 怪血 1.15^f vs 攻击 1.10^n | 制造自然卡关点，驱动转生 |
| 首次转生时机 | 约 14 分钟 / f22~26（S59/S61 真人实测） | 让新玩家第一天体验完整循环 |
| 广告 | 全自愿（结算碎片×2 / 补给箱） | 强制广告是放置类差评第一名 |
| ~~离线收益~~ | **已取消（v2.22）** | 收敛为纯在线循环；CrazyGames 短会话场景离线非主留存 |
| 重塑时机 | **每通关 10 层可选重塑（v2.44）；死亡受阻仍须重塑**；层内不回血、进层回满 | 主动选择提前结算或继续挑战，死亡无硬磨旁路 |
| 碎片经济 | **纯 Boss 掉落累计制（v2.16）**：掉落→runSouls→重塑转可用→树消费；重塑公式产出废止 | 单来源单转换单出口，最简自洽 |
| 装备回收 | 重塑时身上+背包自动转信用点带入新局，回收率 15%（v2.16.1） | 二轮快进前期；全额回收实测作废金币经济 |
| MVP 不做 | 多货币、公会、PvP、剧情、成就 | 等上线数据说话 |

### 5.1 调参历史与重要教训

- **v1.0 → v0.4**：S02 实测 51 层未卡关（太简单）。根因：仿真漏算装备+技能加成（实测玩家战力≈基础值 ×3），转生循环断裂，广告点位零触发
- **教训 1**：放置游戏仿真必须建模装备/技能等效倍率（攻 min(3.0, 1+0.08f)、血 min(1.7, 1+0.03f)、攻速 min(1.66, 1+0.02f)）
- **教训 2**：金币产出∝怪血会形成"收入∝战力"的追赶回路——调难度只能动**成本/产出比**，不能动怪物强度
