# 回到首页与常驻设置 · 设计提案

日期：2026-09-28。作者：Codex。基于实际工程 v2.71。该设计已在正式游戏 v2.72 实施。

## 布局与外观

复用游戏现有灰蓝立体中性按钮。房屋图标和“回到首页”组成长按钮，设置采用同风格齿轮方按钮。信息面板继续使用深色平面背景，操作按钮保留立体厚度，延续用户之前确认的区分原则。

桌面：标题左侧，两个入口位于右侧；顶部吸顶。手机竖屏：顶部 56px 固定操作栏，战斗区紧接其下；下方强化、义体、重塑面板照常滚动。两端按钮视觉高度 36px，齿轮宽 36px，文字 12px；透明扩展区域保留至少 44px 触控高度。手机安全区及横屏仍需正式实施时补充实机验证。

## 第二版 · 按钮缩小

根据用户“按钮尺寸减小”，Codex 将两端按钮由 44px 高缩至 36px，齿轮由 46px 宽缩至 36px，文字由 14px 缩至 12px，并收紧图标与内边距。手机顶部栏由 68px 收至 56px。透明伪元素向外扩展 5px（含边框补偿），以保留 44px 点击高度；齿轮点击范围为 44×44px。第一版备份在 `revision-1/`，当前截图与预览为第二版。正式游戏未修改。
